## A few projects

- **[Orderdesk](https://github.com/nsdmalik/commerce-orderdesk)**: a React ordering workspace with regional pricing and autosaved drafts. It explores what happens when two people edit the same order, prices change, or a save fails.
- **[Shopify Catalog Readiness](https://github.com/nsdmalik/shopify-catalog-readiness)**: a command-line tool that checks product exports for missing information, invalid identifiers and inconsistent variant data.
- **[Pipeline Reconciliation Kit](https://github.com/nsdmalik/pipeline-reconciliation-kit)**: a Python and SQLite example of importing records that arrive late, repeat or disappear from the source.

These projects use fictional data and are separate from my employer's code.
